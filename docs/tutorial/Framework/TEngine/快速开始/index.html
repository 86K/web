快速开始

一、配置项目​

1.克隆项目​

从github上克隆此开源项目到本地：https://github.com/Alex-Rachel/TEngine

2.运行项目​

3.修改资源模式为联机​

4.启用HybridCLR​

二、打包​

1.代码dll打包​

在Unity的菜单栏找到HybridCLR

  • Generate -> All。会自动把ScriptingBackend从Mono2X改为IL2CPP。
  • Build -> BuildAssets And CopyTo AssemblyPath。会自动把构建好的dll放入Assets/AssetRaw/DLL文件夹下。

2.资源打包​

在Unity的菜单栏找到YooAsset

  • AssetBundle Builder -> Click Build

3.exe打包​

  • 通过Unity的File -> Build Settings -> Build进行打包

三、运行项目​

获取远程版本失败。

修改项目中的配置信息：

  • 127.0.0.1：8081 资源下载地址
  • Demo 项目名称
  • Windows64 发布平台
  • DefaultPackage.version 资源版本记录文件

注：因为我们测试的是联机模式，因此需要配置文件服务器。

四、HFS本地测试​

1.下载安装hfs​

下载地址：https://github.com/rejetto/hfs/releases/tag/v3.1.4 使用HFS作为本地的资源管理服务，进行测试。

2.配置hfs​

2.1 创建资源文件夹，把打包出来的资源bundle放入​

Demo：项目名；Windows64：发布平台。

2.2 hfs添加folder​

选择"Real Folder"进行绑定。

3.运行发布包​

配置完成后，再次运行发布的exe： 注：资源版本2026-05-13-844

五、腾讯云存储桶远端测试​

使用腾讯云存储桶作为云端资源管理服务，进行测试。

1.修改项目中资源服务地址​

使用存储桶的云服务器地址作为资源服务地址。

2.重新打包发布exe​

参考步骤二。

3.资源放入存储桶​

4.运行发布包​

注：资源版本2026-05-13-922

六、热更测试​

1.修改代码和图片​

1.1 GameApp.cs中添加打印：测试腾讯云存储桶作为框架联机模式的资源服务器。​

1.2 修改Asset/AssetRaw/UI/BattleMainUI，把TouchButton的Play_Joystick_handle替换为一个红色的五角星​

2.打包并替换存储桶中的资源​

参考步骤四和步骤五。

3.运行发布包​

运行步骤五生成的发布包，即远端连存储桶的版本。
存储桶资源热更.mkv

七、打包工具​

1.使用一键打包工具​

在GameApp.cs中添加打印：测试TEngine的打包工具。
在Unity的菜单栏找到TEngine

  • Build -> 打包工具窗口
  • 基础设置，选择AB输出目录
  • 构建AssetBundle
  • 框架会自动：编译热更DLL -> copy AOT dll -> build package

2.更新存储桶上资源文件​

3.运行发布包​

仍然是运行步骤五生成的发布包（未涉及dll变动，不需要重新构建exe）。
